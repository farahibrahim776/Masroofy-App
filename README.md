# Masroofy App 💸📱

A simple **Java** application focused on helping users manage their personal finances and expenses ("Masroofy" means *my expenses*). Track spending, stay organized, and make better budgeting decisions.

> **Status:** Active development 🚧

---

## ✨ Features

- ➕ Add and categorize expenses
- 🧾 View expense history
- 📊 Basic spending insights (totals / summaries)
- 🔎 Search & filter your records
- 💾 Local data persistence (depending on implementation)

> Feature set may vary based on the current version of the app.

---

- ☕ **Language:** Java (100%)
- 🧰 **Build/IDE:** Android Studio / IntelliJ (depending on project type)

## 🚀 Getting Started

### Prerequisites

- ✅ Java JDK (version depends on the project configuration)
- ✅ Git
- (Optional) Android Studio if this is an Android project 📱

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/farahibrahim776/Masroofy-App.git
   ```

2. **Open the project**
   - If it's a standard Java project: open in IntelliJ IDEA / Eclipse.
   - If it's an Android app: open with Android Studio.

3. **Build & run**
   - Use your IDE's Run configuration, or Gradle/Maven commands if included.
